# 🐍 Snake Game

Классическая игра «Змейка», разработанная с использованием **Python**, **Flask**, **HTML**, **CSS** и **JavaScript**.

Проект создаётся в учебных целях для изучения веб-разработки и разработки игр.

---

## ✨ Возможности

- 🐍 Движение змейки
- 🎨 Отрисовка через HTML5 Canvas
- 🌐 Backend на Flask
- 💻 Простой и понятный интерфейс

---

## 🛠️ Используемые технологии

- Python 3
- Flask
- HTML5
- CSS3
- JavaScript

## 🚀 Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ВАШ_НИК/snake-game.git
```

### 2. Перейти в папку проекта

```bash
cd snake-game
```

### 3. Создать виртуальное окружение

```bash
python -m venv .venv
```

### 4. Активировать виртуальное окружение

**Windows**

```bash
.venv\Scripts\activate
```

**Linux/macOS**

```bash
source .venv/bin/activate
```

### 5. Установить зависимости

```bash
pip install -r requirements.txt
```

### 6. Запустить проект

```bash
python app.py
```

После запуска откройте браузер и перейдите по адресу:

```
http://127.0.0.1:5000
```
